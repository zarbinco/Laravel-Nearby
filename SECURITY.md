# Security

## Reporting a Vulnerability

Private vulnerability reporting is not currently enabled for this repository, and no private security email is advertised.

If you suspect a security vulnerability, [open an issue](https://github.com/zarbinco/Laravel-Nearby/issues/new) asking the maintainers for a confidential reporting channel. Keep that initial message brief and omit exploit details, credentials, personal data, and production data. Share a detailed reproduction only after the maintainers provide an appropriate channel.

In the detailed report, include the package version or commit, PHP and Laravel versions, MySQL version, affected query or model configuration, and a minimal reproduction using synthetic data.

Use ordinary GitHub issues for non-sensitive bugs and questions. The [README](README.md#query-behavior-and-limits) describes supported query shapes, database versions, and calculation limitations.
